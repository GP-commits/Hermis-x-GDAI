# DUSKRIDE

A quiet mountain-bike journey from sunset to sunrise.

**[Play DUSKRIDE](https://gp-commits.github.io/Hermis-x-GDAI/)**

Use left/right arrows or A/D to brake, pedal, and rotate. Space pumps the terrain; R rewinds; Escape pauses. On a phone, hold the left or right half of the screen.

Eight biomes, original procedural artwork, ambient sound, seeded trails, and a two-second rewind. This repository contains the published static game.
