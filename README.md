# DUSKRIDE

A quiet mountain-bike journey from sunset to sunrise.

**[Play DUSKRIDE](https://gp-commits.github.io/Hermis-x-GDAI/)**

Use left/right arrows or A/D to brake, pedal, and rotate. Space pumps the terrain; R restarts at Stage 1; Escape pauses. On a phone, hold the left or right half of the screen.

Eight biomes, original procedural artwork, ambient sound, seeded trails, and one-life competition runs. This repository contains the published static game. Team Hermes × GDAI CUSAT branding is included. Google sign-in, player profiles, and live scores use the backend described in [FIREBASE-SETUP.md](FIREBASE-SETUP.md).
